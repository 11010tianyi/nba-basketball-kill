# NBA 篮球杀快速审阅

范围：单机 AI 局和 `server.mjs` 局域网房间。目标是能开局、能结算、能终场。下面按严重程度列出硬伤；标「已修」的在本分支里改过。

## P0

1. **击杀后可能不终场，场上无人时页面死循环。** 已修。  
   包夹等「先弃牌、再掉体能」的伤害不经过出牌末尾的胜负检查。核心被这样打出场后比赛继续；若场上已没有存活球员，`nextAliveIndex` 会一直找下家，页面卡死。现在离场时立刻判胜负，并且找不到存活球员就终场。

2. **没有响应牌时，进攻结算和 AI 回合叠在一起。** 已修。  
   目标手上没有防守/盖帽时，不进入响应状态，AI 会继续出牌，同时约 0.65 秒后又强制结束回合。快攻还会在下一名玩家的回合里补打。表现为跳回合、同一下进攻结算两次，或快攻打到别人的回合上。现在这段结算会先占住响应位，结束后再衔接后续快攻或结束当前 AI 回合。

3. **暂停会按座位抢走任意人的牌，击杀经常不成立。** 已修。  
   濒死时从 0 号座位开始找第一张暂停，优先消耗玩家自己的牌，也可以拿去救对手。牌堆重洗后暂停会回来，对局会被反复救活。现在先自救，再只允许同阵营自动救援；独狼只救自己，对手的暂停不会被拿走。

4. **残局可以被护臂减伤拖成无限对攻。** 已修。  
   「每轮」减伤原先在每个自己的回合都重置。只剩两人、每人每轮只挨一下时，伤害永远被护臂吃掉，比赛无法终场。现在按一整轮存活球员重置减伤；若同一批人一直没有离场（两人再过一轮，人更多再过六轮），进入绝杀时间，减伤失效，暂停和冠军戒指也不能再阻止离场。

## P1

1. **打出不需要目标的牌后，高亮会落到下一张牌上。** 已修。再点那张高亮牌会把下一张也打出去，或一直弹出「不能出」。现在出牌后会清掉选中；要指定目标的牌可以再点一次取消。
2. **挡拆写的是本回合，实际会留到之后的回合。** 已修。新回合开始时清掉未使用的挡拆。
3. **单机开局也展开局域网面板。** 已修。只有模式切到局域网房间才显示。
4. **抢断/包夹时玩家不能弃装备。** 已修。强制弃牌可以选择装备；手牌上限仍然只弃手牌。
5. **科比第二张进攻牌仍会计分；东契奇每张战术牌都摸牌。** 已修，与角色说明对齐：第二张命中不加分，每回合只有第一张战术牌摸 1 张。
6. **离场时装备直接消失，不进弃牌堆。** 已修。避免牌被悄悄打没。
7. **牌堆和弃牌同时为空时会把空牌塞进手牌。** 已修。摸不到牌就停止，不再访问空牌。
8. **局域网大包和 ping 处理不完整。** 已修。比赛状态若被拆成多帧，会先拼回再解析；ping 会回 pong。
9. **房主页面一关，房间换了房主也不会接手结算。** 未修。服务端只转发，规则引擎在房主浏览器里。房主掉线后其他人会停在最后一次同步。这是结构限制，本次不改架构。
10. **若干技能文案和结算不一致。** 未修，避免在没对上原意时改数值：
    - 艾弗森「响应需求距离 +1」没有接入。
    - 王治郅写的是三分被防后弃牌，代码在命中后才弃。
    - 亚历山大写的是自己的进攻被防后弃牌，代码是他防守成功后让进攻者弃牌。
    - 爱德华兹写的是快攻造成伤害后再摸，代码在打出快攻后立刻摸。
    - 姚明写的是用盖帽响应后摸牌，代码是任意进攻防守成功就摸。
11. **人类响应会结束 AI 本回合剩余的出牌额度。** 未修。这样不会再和结算链叠回合；AI 仍会正常结束并轮到下家。

## 打一小局

```bash
npm start
```

浏览器打开 `http://127.0.0.1:4173/`，模式保持「单机 AI 局」，选球星后点「开球」。回合内点手牌再点目标；误选再点同一张牌取消。无牌可出时点「结束回合」，或等倒计时。终场弹窗出现即一局结束。

局域网：先 `npm start`，房主创建房间，其他人用终端里的 LAN 地址加入并准备，房主再开球。房主页面要保持打开。

验证：

```bash
npm run check
npm run check:play
```

`check:play` 会连本机房间做创建/加入/开球，并用无头 Chrome 把一局单机 AI 打到终场弹窗。需要本机有 Chrome。
